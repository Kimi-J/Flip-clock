## 1. 产品概述

全屏翻页时钟是一款桌面端 web 应用,以经典机械翻页时钟为灵感,呈现沉浸式的时间显示体验。
- 解决传统数字时钟缺乏质感与仪式感的问题,为工作、冥想、专注场景提供优雅的时间陪伴
- 面向追求桌面美学、需要专注时间提示的创作者、学生与办公人群

## 2. 核心功能

### 2.1 功能模块
1. **时钟主界面**:翻页小时、翻页分钟、翻页秒,12/24 小时切换
2. **状态信息区**:日期、星期、问候语、在线时长
3. **设置面板**:主题切换、12/24 小时制、秒针显隐、字体选择、背景模式

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 时钟主界面 | 翻页时钟核心 | 时:分:秒三组翻页卡片,真实 3D 翻转动画 |
| 时钟主界面 | 日期信息条 | 年月日、星期、动态问候语 |
| 时钟主界面 | 设置浮层 | 主题、制式、显示项、背景切换 |
| 时钟主界面 | 氛围背景 | 渐变光晕/粒子/噪点纹理,主题自适应 |

## 3. 核心流程

用户打开应用即进入全屏时钟界面,翻页卡片随时间跳动;通过右上角齿轮唤出设置浮层,实时调整主题与显示项;鼠标移动显示控制条,静止后自动隐藏以保持沉浸感。

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**:深色背景 (#0a0a0f → #1a1a2e 径向渐变) + 暖琥珀色翻页卡 (#f4a261/#e76f51) 作为强调
- **次要主题**:极简白(米白卡 + 深灰字)、午夜蓝(深蓝卡 + 冷光字)、复古绿(墨绿卡 + 荧光字)
- **卡片样式**:圆角 12px,顶部高光 + 底部阴影模拟物理厚度,中线分割条
- **字体**:显示数字使用 "Bebas Neue" / "Oswald" 等高瘦几何无衬线;日期使用 "Noto Sans SC"
- **布局**:水平居中三组翻页卡,卡组间冒号呼吸闪烁;底部信息条,顶部细线装饰
- **图标**:线性极简 SVG 图标,1.5px 描边

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 时钟主界面 | 翻页卡组 | 3D 翻转动画、径向渐变背景、卡片高光阴影、中线分割 |
| 时钟主界面 | 信息条 | 日期文字、星期胶囊、问候语淡入 |
| 时钟主界面 | 设置浮层 | 毛玻璃背景、选项卡片、滑块开关 |
| 时钟主界面 | 氛围层 | 浮动光晕、细微噪点、鼠标视差 |

### 4.3 响应式
- 桌面优先,全屏铺满,翻页卡尺寸根据视口动态缩放(vmin 单位)
- 移动端自适应:缩小卡片、隐藏秒针选项、纵向堆叠信息条
- 触摸优化:点击空白处唤出/隐藏控制条

### 4.4 动画细节
- **翻页动画**:上半卡沿中线 X 轴 -90deg 翻转,下半卡同步 90deg → 0,持续 600ms,贝塞尔缓动
- **加载入场**:三组卡依次从底部上浮 + 淡入,间隔 150ms
- **冒号呼吸**:每秒透明度 0.3 → 1 循环
- **背景光晕**:缓慢漂移 20s 循环,营造呼吸感
- **设置浮层**:从右侧滑入 + 背景模糊渐显
